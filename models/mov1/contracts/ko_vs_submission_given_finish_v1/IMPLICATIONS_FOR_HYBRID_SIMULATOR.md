# MOV1 V1: eventual simulator interpretation

This is a frozen interpretation plan, not a trained-model finding. The eventual run must assess the decomposition pre-fight state → finish/survival probability → conditional finish pathway → KO/TKO versus submission.

Report whether S2 improves probability quality beyond S1 and whether striking/grappling archetypes receive coherent three-way composition. Examine both total finish probability and method split, using actual matching OOF-cell rates rather than the longer audit sample as predictive truth. Check divisions, time, round structure and uncertainty. Record contradictory cells and sparse denominators.

Conditional success does not automatically establish complete-system calibration. With a shared frozen F node, log-loss differences have a finish-weighted algebraic relationship; multiclass Brier and classwise reliability provide additional evidence. MOV0 errors and division/context deficiencies may remain even with a useful K node.

No descriptive audit rate or logistic coefficient is a causal hazard, action probability or round transition. Ground strike share does not locate a KO. This task and the eventual MOV1 run do not build simulator states or transitions. Any later simulator requires separately governed dynamic data and validation.
