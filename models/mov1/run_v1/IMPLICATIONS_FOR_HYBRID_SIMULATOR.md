# Hybrid simulator implications from the first frozen MOV1 run

Retain the finish/survival → conditional KO/submission probability decomposition as a useful predictive reference architecture. MIN improves conditional log loss beyond context in9/9 years; S2 improves three-way log loss and Brier over S1 and S0, with favorable paired uncertainty intervals. FULL adds no supported value beyond MIN in this specification.

Damage environments receive more KO concentration; takedown/submission environments receive more submission concentration than context alone. This is a more coherent decomposition than using one historical UFC-wide method split. The pathway report also shows incomplete submission enrichment (B3/B5), overconfident conditional spread, women’s Strawweight mismatch and frozen-F survival errors. Preserve these limitations as future validation targets, without modifying this run.

This supports retaining two conditional probability nodes for future research, not implementing a simulator now. Fight-level probabilities, coefficients and descriptive archetype rates do not identify time-varying causal hazards, standing-versus-ground KO location, actions, positions or round transitions. Simulator data/transition methodology needs separate governance and validation. No simulator code or transition rate is created here.
