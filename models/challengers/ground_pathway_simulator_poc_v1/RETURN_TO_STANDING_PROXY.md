# ESTIMATED_RETURN_TO_STANDING_PROXY
For actor A, reference successful access r0=A TD attempts/min * A shrunk TD conversion. Return hazard r0*(1-qA)/qA, primary multiplier 1. This inverts a two-state stationary occupancy approximation so own successful access and control proxy imply a mean episode duration. Matchup entry=A access * sqrt(A TD conversion * (1-B TD resistance)). qA is the directional exposure proxy. Return sensitivities multiply by 0.5/2 without selecting a winner. This is not measured escape, stand-ups, scrambles or disengagement; no fabricated opponent escape ability. Round-end reset additionally returns to standing.
