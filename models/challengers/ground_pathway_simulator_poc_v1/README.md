# Simplified ground-pathway simulator POC V1
Independent experimental implementation after merged #161. No #162 content used. Run `python models/challengers/ground_pathway_simulator_poc_v1/run.py --freeze <published-preregistration-SHA>` then `python models/challengers/ground_pathway_simulator_poc_v1/verify.py`. Requirements pinned in requirements.txt. Outputs under run_v1/. No model promotion or merge. Exact CTMC is a coarse assumption-driven process, not a reconstruction of observed positions.

Conceptual inspiration: Holmes, McHale & Żychaluk (2023), A Markov chain model for forecasting results of mixed martial arts contests, IJF39(2),623–640, DOI10.1016/j.ijforecast.2022.01.007. Similarities: generic ground state, actor/opponent skills, TD access, SUB/GnP activity, shrinkage and approximate return. Differences: current governed source fields, modern frozen chronology, actor-oriented state copies, exact CTMC propagation, external MOV0 composition; none of the paper's constants copied. Article metadata/abstract independently retrieved; full publisher access returned403 in this session. Detailed motivation also follows the attached governed research; this is not an exact reproduction.
