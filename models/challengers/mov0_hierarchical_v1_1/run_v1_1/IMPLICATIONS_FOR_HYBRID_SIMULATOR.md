# Implications for hybrid simulator

The fitted relationships do not establish that environment-conditioned finish hazards improve generalization. Global effects remain a sufficient reference for this comparison; the tested class deviations are uncertain and add no clear probability-quality benefit. Survival has a negative global conditional association, while Heavyweight/LHW survival deviations remain uncertain. Partial pooling is a computationally feasible, interpretable candidate for a later separately specified state/hazard experiment, especially where group information differs, but this result provides no recommendation to deploy it. Weight-class-specific knockdown, submission or grappling-entry hazards are not justified by these posterior deviations. Logistic coefficients must not be copied into transition hazards: bout-level associations are not time-dependent rates, causal effects or state transitions. No simulator code or transitions were implemented.
