# UFC_EDGE_GROUND_EXPOSURE_VENDOR_SAMPLE_AND_RIGHTS_GATE_V1

## Goal and order

Establish whether a lawful final historical archive can supply genuine ground seconds for the fixed 28-fight panel, then determine whether it covers the existing chronological populations. This is acquisition feasibility only; no subscriptions, purchases, accepted commercial licenses, models or production integration.

1. Seek an authorized Sportradar final detailed-results sample and field-level archive census. The public live example is not the final archive. Confirm the current documented final REST endpoint rather than guessing a URL.
2. Ask FightGeek about the actual complete UFC Precision archive, including early history, submission/GNP finishes and 2023–2026; the published decisions-only subset does not answer this.
3. Ask UFCalendar for exact upstream lineage, rounding and authenticated evaluation records for this same panel. A seconds field without records is insufficient.

No outreach has been sent. The project owner must authorize any provider communication and account/license action.

## Questions to put to each provider

- Define grounded, top, bottom, ground control, generic control, neutral ground, scrambles and one upright/one grounded. Are distance/clinch/ground exclusive? What clock pauses count?
- Are durations directly observed at second/subsecond resolution, floored minutes converted to seconds, or reconstructed? Supply rule changes and rounding policies.
- Provide the fixed panel's final per-round records, or an explicit missing reason for each. Include event/date, both fighter IDs, bout ID, round, duration and revision status. Do not substitute different bouts.
- Give per-year/per-division eligible UFC bouts and nonmissing counts for each required field, including pre-2015 prior histories and every 2018–2026 period through 2026-08-15. Explain gaps and longitudinal fighter continuity.
- Identify original collection process, correction timestamps, finalization lag and availability of historical publication vintages. Today’s final stats are not proof of contemporaneous availability.
- Quote the bounded historical scope separately from live services; provide permitted research/model use, retained snapshots after cancellation, derivatives/aggregate publication and raw evidence redistribution. No purchase yet.

## Required verification deliverables

Use `SAMPLE_SELECTION.json` and `SAMPLE_PANEL.csv` unchanged. Extend the comparison CSV with authorized actual values and source/version references; preserve null, unknown and zero separately. Record a candidate's precision, generic control, top/bottom and ground-control definitions, action alignment, discrepancies and missing reasons per round. Diagnose 60-second lattice patterns against legacy buckets, without assuming that an occasional multiple of 60 proves truncation. Reconcile mutually exclusive states only when provider definitions warrant it. Compare corrected final strike counts with the supplemental live-example differences.

Require reliable identity joins and document any corner changes/rematches. Produce a field-level year/division census and recompute prospective historical availability using strict prior event dates without fitting a model or altering populations. Keep licensed raw exports out of public GitHub unless permission explicitly permits them; publish reproducible checks and permitted derived evidence.

Decision A requires adequate verified historical exposure and rights. B requires verified partial coverage and a predeclared narrower research population, without post hoc replacement. C requires demonstrated inadequate semantics such as converted minute buckets. D remains appropriate when no existing source can pass. Authentication failure alone proves none of those semantic claims.
