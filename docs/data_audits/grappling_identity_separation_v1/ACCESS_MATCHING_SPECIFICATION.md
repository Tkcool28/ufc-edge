# Frozen access matching

ACCESS = jointly observed TD attempts / governed total elapsed minutes. Three complete measured bouts and >=15 minutes screen broad support. PR160 used per15; division by 15 only changes units. Boundary average-rank quartiles use supported training-fighter snapshots. Block cuts are learned from first-three histories only and carried unchanged to next-three histories. Same-quartile pairs are primary; crossing strata are retained in block_states.csv.gz. Quartiles permit residual access variation and do not match opponents, TD completion, or actual ground opportunity.

See access_edges.csv, separation.csv and region_replication.csv. Within-stratum rank centering is descriptive removal of broad access strata; no outcome model is fitted. Regions use fixed first-side medians with equality in low. They are hypothesis checks, not four natural fighter classes.

Histories use strict event-date priors with target and same-date exclusion, sealed through 2026-08-15. Continuous behavioral rates do not establish intention, top control, true ground exposure or causal effects. This is developmental historical evidence; repeated fighters and nested boundaries are dependent. No predictive model or prospective confirmation outcomes were used.
