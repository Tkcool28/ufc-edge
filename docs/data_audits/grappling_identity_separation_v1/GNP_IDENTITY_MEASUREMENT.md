# Secondary ground-striking tendency

GNP = significant ground-strike attempts / jointly observed total elapsed minutes, >=3 measured bouts and >=15 minutes. PR160 deferred primary GnP expansion; this experiment measures its existing total-time tendency without promoting a third identity. GnP success never affects classification.

GnP is not promoted merely because it has low redundancy: repeatability is still required. Ground activity can follow knockdowns, bottom exchanges or opponent takedowns. It omits nonsignificant punches and has no ground-KO attribution. No genuine ground-minute rate is claimed.

Histories use strict event-date priors with target and same-date exclusion, sealed through 2026-08-15. Continuous behavioral rates do not establish intention, top control, true ground exposure or causal effects. This is developmental historical evidence; repeated fighters and nested boundaries are dependent. No predictive model or prospective confirmation outcomes were used.
