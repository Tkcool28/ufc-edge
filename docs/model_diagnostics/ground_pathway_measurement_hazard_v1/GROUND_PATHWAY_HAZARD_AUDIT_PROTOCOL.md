Training-only aggregate oracle diagnostics use frozen January-1 division priors and saved training support. A homogeneous population matchup with three scheduled rounds supplies finite-horizon alive-time reward rates. Occupancy oracle targets twice division decision-control share (bounded to 0.02–0.95) by solving for a common return factor on that training-only matchup. This is generic CTRL, not ground truth. Attempt oracle scales creation by 2*division SUB/min divided by population expected attempts/expected alive minutes. Conversion oracle replaces conversion with coherent division training successes/attempts, falling back to global if zero denominator. Combined oracle uses attempt plus conversion while retaining original entry/return. These are aggregate proxy replacements, not individual oracle ground truth or deployable models. Save every training-derived factor/support; no target-fight outcome sets a probability.

Report all defensive support and ratios against division baselines.

Root cause assessment uses mechanistic identities, training proxy consistency, isolated response curves and oracle recovery together. A proxy oracle recovering >=25% of conditional LL gap and SUB deficit is material; >=50% on both is potentially dominant, only if independent measurement evidence agrees and alternatives are not material. No causal dominance inferred from sensitivity alone. If multiple mappings are material choose E; if proxies cannot isolate causes choose G. F requires unfavorable oracle recovery, not merely failure of primary. Preserve positive whole-identity ablation evidence.
